# קובץ ייבוא ל־Shopify: נעלי כדורגל חדשות משני ספקים

## מה תקבל
קובץ CSV אחד, מוכן להעלאה ישירה ל־Shopify (Products → Import), רק עם נעליים שעדיין אין בחנות. בכל מוצר יהיו:
- כותרת בעברית בסגנון הקיים באתר (חברה + דגם + צבע + סוג סוליה)
- תמונה ראשית ברורה (הנעל מהצד, בלי כיתובים או אריזה), ועוד עד 6 תמונות מזוויות שונות
- תיאור קצר בעברית: דגם, סוג סוליה, למה היא מתאימה, טבלת מידות
- מידות לפי מה שהספק מציע (בדרך כלל 39–45, ומידות ילדים כשיש)
- מחיר לפי המחירון: מקצועית 450 ₪, חצי מקצועית 400 ₪, רגילה 300 ₪

וגם גיליון סיכום: כמה נעליים נמצאו לכל חברה ולכל דגם.

## התגים בכל מוצר
| תג | איך נקבע |
|---|---|
| קהל: גברים / נשים / ילדים | לפי שם האלבום והמידות. אם יש מידות ילדים (למשל 28–38) — ילדים. ברירת מחדל: גברים |
| סוג מוצר: נעליים | קבוע לכל המוצרים, גם בשדה Type |
| צבע | הצבע הדומיננטי: קודם לפי השם, ואם אין — לפי התמונה הראשית, ואבדוק בעין |
| חברה | נייקי / אדידס / פומה / מיזונו / ניו באלאנס / אסיקס / ג'ומה / אחר |
| דגם | Phantom, Mercurial, Tiempo, Predator, F50, Copa, Future, Ultra, Morelia, Tekela וכו' |
| סוג הנעליים: פקקים / פקקונים | FG / SG / AG / MG = פקקים. TF / IC = פקקונים |

## שלבים
1. לסרוק את שני הקטלוגים (בקישור הראשון — כל תוצאות החיפוש "SG", בשני — כל האלבומים) ולשמור רק נעלי כדורגל.
2. להשוות לנעליים שכבר יש באתר, וגם בין שני הספקים, לפי תמונות ולא רק שמות, כדי שלא תהיה אף נעל פעמיים.
3. לזהות חברה, דגם, סוג סוליה, קהל וצבע לכל נעל, ולתרגם לעברית.
4. לבחור תמונה ראשית לכל מוצר ולהוריד תמונות כפולות.
5. לבנות את הקובץ, לבדוק שהתמונות נטענות, שאין כפילויות ושלכל מוצר יש את כל ששת התגים.

## דברים שחשוב לדעת
- **רמת המחיר:** אקבע לפי שם הדגם. Elite / Pro / Elite SG = מקצועית (450 ₪), Pro / Club-Pro = חצי מקצועית (400 ₪), Academy / Club / League = רגילה (300 ₪). אם השם לא מראה רמה — חצי מקצועית. אפשר לשנות אחרי ההעלאה.
- **אלבומים נעולים בסיסמה** ידולגו. אם יש לך סיסמה, שלח לי ואוסיף אותם.
- תמונות שיש עליהן כיתוב בסינית או סימן מים של הספק לא יהיו תמונה ראשית אם יש חלופה.
- התמונות נטענות דרך האתר שלך, אז הוא צריך להיות פעיל בזמן ההעלאה. אין צורך לסמן "Overwrite" כי כל המוצרים חדשים.

## פרטים טכניים
- אותו פורמט כמו קבצי הייבוא הקודמים: Handle, Title, Body (HTML), Vendor, Type, Tags, Option1 Size, Variant Price, Image Src, Image Position.
- Handle קבוע לכל מוצר (לפי מזהה האלבום אצל הספק), כדי שייבוא חוזר לא ייצור כפילויות.
- כפילויות יזוהו לפי טביעת תמונה (perceptual hash) מול מוצרי הנעליים הקיימים במסד הנתונים ובין הספקים.
- התמונות דרך /api/public/img בכתובת הקבועה של האתר. אם אחד הספקים משתמש בשרת תמונות שלא מאושר כרגע, הוא יתווסף לרשימת השרתים המאושרים.
- קבצים: `golassos-new-boots-shopify.csv` וגיליון `golassos-new-boots-summary.csv`.
